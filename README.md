# AI Deliberate Practice Skill

把 AI 从“讲解者”变成“刻意练习教练”：通过真实场景、主动尝试、暴露错误、追问纠偏、再次尝试和迁移测试，训练真实使用能力。

## 适用场景

- 我没理解 / 卡住了
- 别讲概念，直接练
- 帮我设计学习路径
- 我觉得我掌握了，帮我检查漏洞
- 高压场景训练我
- 别只看答案，看我的思考过程
- 我来教你，检查我是否真懂
- 记录每次练习结果
- 自动生成学习进度表
- 生成题库 / 训练卡
- 输出长期掌握度评分

## 安装到 Codex

复制本仓库的 `SKILL.md` 到：

```text
~/.codex/skills/ai-deliberate-practice/SKILL.md
```

推荐目录结构：

```text
~/.codex/skills/ai-deliberate-practice/
└── SKILL.md
```

重新打开 Codex 后即可使用。

## 安装到 Obsidian vault

也可以复制到你的 vault：

```text
90-system/skills/ai-deliberate-practice/SKILL.md
```

## 隐私说明

该 Skill 是通用训练流程模板，不包含个人路径、密钥、账号、公司业务信息或私有项目名。

## 新增能力

`SKILL.md` 现在内置训练档案协议：练习记录、学习进度表、题库/训练卡和 0-5 掌握度评分。默认仍不写代码、不调用 API；只有用户要求追踪或保存时才生成档案，避免把普通练习变成管理负担。
